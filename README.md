## Portable PHP

This project includes a portable PHP runtime in `tools/php`.

Check PHP:

```powershell
.\php.cmd -v
```

Start a local PHP server from the project root:

```powershell
.\php.cmd -S localhost:8000
```

Seller registration page:

```text
http://localhost:8000/Liu%20Ruoqi/register.php
```

Import `Liu Ruoqi/database.sql` into MySQL before opening the PHP pages.
